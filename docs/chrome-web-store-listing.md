## Store listing

- **Name:** AI Capacity Monitor
- **Summary:** See your selected AI-service balances and usage limits in one
  local popup.
- **Category:** Productivity
- **Single purpose:** Shows your AI service balances and usage limits from
  provider pages you are already signed into.
- **Support URL:** `https://github.com/tonyperkins/ai-capacity-monitor/issues`
- **Privacy-policy URL:**
  `https://github.com/tonyperkins/ai-capacity-monitor/blob/main/docs/privacy-policy.md`
  (valid once the repository is public)

## Description

AI Capacity Monitor keeps the displayed AI-service credit balances and plan
limits you choose in one browser popup. Enable providers one at a time, review
their first reading, and see a clear state when a page needs sign-in, access,
or another attempt.

The extension works locally by default. It never asks for credentials. Optional
publishing is off until you configure and acknowledge a local bridge or HTTPS
webhook destination.

## Privacy-practices entry

Use the single-purpose statement above. Declare that the extension handles
financial information and website content only as needed to show the selected
provider readings, stores derived values locally, and transmits normalized
derived snapshots only to a destination explicitly configured by the user.
Use the permission justifications in
[web-store-permissions.md](web-store-permissions.md). Certify the Limited Use
statements only after confirming the public policy and in-product disclosures
match the reviewed build.

## Distribution plan

1. Upload the deterministic ZIP generated by `python3 scripts/package-extension.py`.
2. Complete the listing, Privacy, and Distribution tabs.
3. Select **Unlisted** for the first beta round; configure test instructions
   without collecting or providing provider credentials.
4. Select deferred publishing before submitting for review. Do not select a
   public release until the Phase 1 beta exit gate has been met.
