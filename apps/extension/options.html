CAPACITY MONITOR

Collection settings

Choose which providers are read, whether the extension collects in the background, and where snapshots are published. Privacy policy

Providers

Only enabled providers are read. Turning one on asks Chrome for access to that provider's site; disabling it stops collection and removes its stored readings. You can separately remove retained site access.

Collection

When enabled, Capacity Monitor keeps its provider tabs in a separate minimized Chrome window. Collection never restores or focuses that window; sign-in actions still open the provider in your current window. Manual collection and the individual card refresh buttons remain available when automatic updates are paused.

Diagnostics

Shows the last safe collection outcome for each enabled provider. Diagnostic codes never include page text or account information.

Publishing

When enabled, each collection posts the snapshot contract payload (validated metrics and diagnostics only — never page content) to the chosen destination. Failed deliveries queue and retry with backoff; local readings are never affected. The bridge must be a loopback address; a webhook must use HTTPS.

Before publishing

Choose a destination to review what it will receive.

Local data

Delete all local Capacity Monitor data from this browser profile: readings, diagnostics, history queue, preferences, configured destinations, and saved secrets. This does not remove optional site permissions; remove those from the provider controls above.
